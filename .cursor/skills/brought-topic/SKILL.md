# 自带题目

先评判，再决定写不写。题目没有过下面的门槛时，只列出问题和改法，不写研究方案，也不写研究计划。

## 门槛

题目 8 到 60 字。破折号前面的主标题不超过 40 字。

不用这些字：浅析、浅谈、现状、对策、探析、探究、研究综述、创新路径、若干思考、刍议。

做法要和题目一致：

- 定量：写明条件和结果，用「对……的影响」「与……的关系」，或写明中介、调节。横截面调查写成关联，不用「导致」「造成」。对象要能指认到一类人、企业或场所。
- 定性：用「如何」「怎样」「何以」「形塑」写出要理解的过程。只有「对……的影响」而没有过程时，改成定性问法，或改做定量。「如何提升、促进、优化」而没有具体过程，不算合格。
- 文本分析：用书名号或文本类型写明一份可以逐条摘录的文本，并写要抽出的现象。结论停在这一份文本。
- 元分析：题目含「元分析」，并写明两个变量的关系。题目里不写合并效应、I²、p 值或具体系数。

看不出做法、看不出两件事、或对象与文本没有着落，都算不合格。

## 不合格

逐条写题目现在的问题，以及要改哪几个字。可以给一个改写方向，用【】标出仍须本人填写的对象或文本。不编造作者、年份、篇名、期刊、DOI、系数和访谈原话。

## 合格之后

用题目里已经出现的词写研究方案和研究计划，不另起一个研究。

研究方案写四件事：一句和研究题目用词一致的研究问题；问卷、访谈、一份文本的类目，或检索与摘录；对象、文本或纳入范围，题目里没有的地点和人群写成【待补】；工具要包含的部分。不抄成熟量表的原题。

研究计划按这个顺序：

1. 用题目中的现象和对象检索 2021 年以来的文献。没有打开页面核对的条目不写入，需要补出处时标【待核验】。
2. 准备工具。
3. 收集、访谈、编码或摘录。
4. 结果在本人核算或摘录之后写入。方案和计划里不出现样本均值、系数、合并效应和访谈原话。

定量不把横截面写成因果。文本分析不把一份文本写成该类文本的全体。元分析不在摘录前写出合并效应。
