# 结果分析

结果只报告已经发生的分析。解释、政策和与文献的对照放到结论。

## 没有结果时

用户没有给出核算汇总、编码表或访谈材料时，不写任何发现。按预先登记的分析写出待填位置：要报告哪一项、数字或摘录从哪里来、哪一类句子现在不能写。不出现系数、p 值、均值、κ、类目条数，也不编访谈原话和字幕例句。

## 有结果时

数字、原话、摘录必须来自用户给的汇总或材料，原样使用，不四舍五入成另一个数，不补一个没跑过的模型。

- 定量：先写样本里实际有哪些人，再写预先规定的检验，再写方向和幅度。横截面问卷只写关联。没有识别设计时，不写「导致」「影响了」。统计显著不等于这个差别重要；幅度要用题目里的变量单位说明。
- 定性：每个主题下只使用材料里出现过的说法，并说明来自哪一次访谈的哪一类情境。不把一位受访者的话写成「大家」。
- 文本分析：每个判断都要能回到页码、时间码或段落。类目条数只在编码表里有计数时才写。不把一份字幕、一组报道或一份条例写成该类文本的全体。

## 不写进这一节

政策建议、理论意义、文献谁对谁错、本研究的局限。这些属于结论。
