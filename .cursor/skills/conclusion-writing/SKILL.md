# 结论

结论回答引言里的那一个问题，用词与引言一致。没有写进结果的发现，不能在结论里出现。

## 先答问题

结果仍是待填时，只写「结果填入之后，结论只允许回答引言中的这个问题」，不要提前写出回答。结果已经写明时，用一段话给出回答，并保留结果里的限定：关联还是过程，一份文本还是一组人。

定量的横截面调查不升格成因果。定性不把访谈主题写成总体比例。文本分析不把一份作品写成所有同类文本。

## 局限只写一处

局限集中成一段，不在每段末尾重复。写三件已经发生的事：

- 对象的边界：一个场所、一批受访者，或一份文本；
- 设计的边界：横截面、访谈是否收到新主题不再出现、文本的版本和未纳入部分；
- 没有测到或没有读到的东西。

不写「样本较小，后续可以扩大」这种放之四海的句子，除非它对应上面三条里的一条。

## 收尾

用一句话写下一步能做的事，而且必须沿同一类设计：再做一次调查、再访谈一类人，或再读一份文本。不以空泛口号收尾，不用「具有重要的理论意义与实践意义」。

公共卫生、流行病学、老龄化稿件如果要按显著性差异写社会解释和政策含义，每一节用一个观点作小标题，节内依次写本文证据、社会解释、与既往研究的异同。没有检验过的亚组差异不要写成结论。
